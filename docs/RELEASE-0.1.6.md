# RecipeBalancer 0.1.6 (1.21.1)

## GitHub Release 说明

适用于 **NeoForge 1.21.1** 的纯客户端版本（一条产线配平计算器）。

- **配方集界面新增「打开文件夹」**：底行「返回」与「读取」之间新增按钮，直接用系统文件管理器打开工作区目录（配方集 json 所在处），方便外部复制 / 粘贴配方集。
- **物料清单编辑屏支持 JEI 拖拽**：「无限外部供应物质」「循环亏损补充物质」的网格可直接从 JEI 拖入物品，追加到清单末尾。

需要 **Java 21**。

## Modrinth / CurseForge 更新描述（纯英文）

```
- Added an "Open folder" button on the recipe set screen that opens the workspace directory directly
- JEI drag & drop is now supported on the material list screens (infinite supply / cyclic deficit)
```
