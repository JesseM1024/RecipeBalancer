# RecipeBalancer 0.1.2 · 首个公开版本（NeoForge 1.21.1）

0.1.x 阶段：求解器与录入界面已完整，流程图仍在打磨。首版可直接用于日常配平。

## 功能

- **配方录入**：一条配方一行（原料 / 产物 / 耗时 / 设备）。物品从背包点选、从 JEI 拖 ghost，或在 JEI 配方页按加号把整页槽位与数量导入；耗时与设备始终手填。
- **目标**：最多 32 个，逐个指定速率，单位 `/t`、`/s`、`/m`、`/h`。
- **数量输入**：支持算式 `+ - * / ^` 与紧凑后缀（`k`、`M`、`μ`、`m`、`n`…）；耗时同样支持算式与 `t/秒/分/时`。
- **线性规划求解**：输出每条配方的稳态速率、机器并行数、外部输入、副产物。目标函数可选「最小机器总量」或「最小配方活动量」。
- **循环配方**：按强连通分量做亏损检测（亏损循环要求外部输入），完美循环给出最小启动投料。
- **无解如实报无解**：`INFEASIBLE` / `UNBOUNDED` 直接显示，不用近似值顶替。
- **结果展示**：文本报告 + 分层流程图（橙=配方、绿=外部输入、蓝=中间产物、红=启动库存、黄=副产物、紫=目标；线宽对应 `/t` 流量），可拖动、缩放、拖节点。
- **HTML 导出**：流程图导出为单个自包含 HTML 文件。
- **自动保存**：输入即存到 `config/recipebalancer/scenarios/autosave.json`，未填完的草稿也保留。
- **带组件物品**：药水、附魔书、改名堆叠保留完整 `ItemStack` 身份。
- **JEI 软依赖**：装了可拖 ghost、导入配方、R/U 查合成；不装全部核心功能照常。
- **中英双语界面**。

## 已知限制

- 仅稳态：不模拟缓冲、预热与瞬态。
- 不读取其它模组的配方库（GregTech / Mekanism 等不接），JEI 是唯一自动录入通道，且只填物品槽。
- 纯客户端：服务端无需安装；多人游戏下不做同步，各人各算各的。
- 稠密单纯形，上千条配方的场景求解明显变慢。
- 流程图大场景布局耗时较长；完美循环投料的图面展示仍在完善。

## 安装

把 `recipebalancer-0.1.2-1.21.1.jar` 放进 `mods`。需要 Minecraft 1.21.1 + NeoForge 21.1.x，无前置依赖。
JEI 19.39+ 可选。
