# RecipeBalancer 0.1.4 · JEI 低版本补齐（NeoForge 1.21.1）

相对 0.1.3 的增量版本。0.1.3 把 JEI 编译基线降到 19.8.4，但低版本功能是缺的，本版补上。

## 新增

- **JEI 19.39 之前也有配方页按钮**：低版本没有 `IRecipeButtonControllerFactory`，改用
  `IRecipeCategoryDecorator` 自绘同款 13×13 按钮，按 `getAllRecipeTypes()` 覆盖全部配方类型
  （含模组机器配方）。按钮与 JEI 自带侧边按钮同列对齐，悬停高亮，松开左键后打开配方编码终端并预填编码。
- **低版本 JEI 的 R / U / A**：新增全局 GUI 处理器，在编码主界面的目标产物、配方库、编码区、背包上
  悬停物品即可查配方、查用途、加书签（此前只有 19.39+ 可用）。

## 修复

- 求解结果页、缩放系数页未向 JEI 声明界面位置，导致 JEI 物品面板/书签面板不渲染。
- 首次打开界面时左侧书签列与历史列不显示：JEI 在 `Screen#init()` 之前就会查询界面属性，
  那时面板几何还是占位值，被 JEI 当作「左侧无空间」缓存了下来。现在布局就绪前不报属性。

## 变更

- 移除进入世界时关于 JEI 版本过低的聊天栏提示。
- 版本号 0.1.3 → 0.1.4。

## 安装

`recipebalancer-0.1.4-1.21.1.jar` 放入 `mods`。需要 Minecraft 1.21.1 + NeoForge 21.1.x，
JEI 可选（19.8.4 及以上）。
